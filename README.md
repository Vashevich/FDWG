# FDWG — просмотр чертежей в браузере

Страница `index.html` открывает векторные чертежи **DXF**, **SVG** и **DWG** прямо в браузере. Файл никуда не отправляется.

## Что умеет
- Перетащить файл на страницу или нажать «Открыть файл» (кнопка «Открыть пример» показывает учебную квартиру).
- Слои включаются и выключаются галочками.
- **ПКМ**: двигать чертёж (рука). **Колесо**: масштаб.
- **ЛКМ**: рулетка. Первый клик ставит начало, второй показывает размер (длина, Δx, Δy). Третий клик начинает новый замер. Рулетка помнит 4 последних замера, предыдущие бледнеют, пятый замер стирает самый старый. Рулетка прилипает к концам и углам линий (`SNAP` в начале скрипта).
- **Esc**: сбросить начатый замер. «Вписать»: показать весь чертёж.
- **3D**: слои стен (по названию: `wall`, `стен`) выдавливаются на заданную высоту, остальное лежит на плане. Левая кнопка вращает, правая двигает, колесо меняет масштаб.

## Что поддерживается
- **DXF** (текстовый): LINE, LWPOLYLINE, POLYLINE, CIRCLE, ARC, ELLIPSE, SPLINE, TEXT, MTEXT, LEADER, 3DFACE, SOLID, INSERT (блоки), DIMENSION (через блок размера). Единицы берутся из `$INSUNITS`. Не показываются HATCH, изображения, штриховки, сетки.
- **SVG**: path, line, polyline, polygon, rect, circle, ellipse. Слоями служат группы с `id` или `inkscape:label`. Текст в SVG пока не показывается.
- **DWG**: через библиотеку libredwg-web, она подгружается из интернета только при открытии DWG. Блоки DWG в этой версии не раскрываются. Если библиотека не загрузилась, страница подсказывает сохранить чертёж как DXF.

## Примеры
`examples/kvartira.dxf`, `examples/kvartira.svg`.

## Запуск
Откройте `index.html` двойным щелчком или выложите репозиторий на GitHub Pages (Settings → Pages → Deploy from a branch → `main`, папка `/`).
